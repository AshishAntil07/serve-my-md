# Routing and Sidebar Patterns

## `index.md` is landing page

- `index.md` represents the landing page for its directory.
- `index` is not part of URL pathnames.
- In nested name handling, `index.md` maps to `""` (empty string).

## Grouping directories with parentheses

Directory names wrapped in `()` act as grouping buckets:

- shown as grouped section in sidebar
- skipped from route pathname segments
- should not contain `index.md`

This is useful when you want visual grouping without adding extra URL segments.

Example:

```text
docs/
  (Guides)/
    setup.md
```

Route:

- `/setup`

## Regular directories (without parentheses)

- appear as collapsible sidebar containers
- can have `index.md` and be clickable landing pages
- are included in pathname segments of child files

Example:

```text
docs/
  guides/
    index.md
    setup.md
```

Routes:

- `/guides`
- `/guides/setup`

## Ordered filenames with index prefixes

If you use names like:

- `1. blahblah.md`
- `2. blhalbhablah.md`

and set trimming in config (see config docs), names can be ordered while emitted as clean paths.

## Slug generation rules

Route path segments are normalized by the CLI:

- converted to lowercase
- spaces/underscores become `-`
- punctuation like `.,;"'\\:<>`?!` is removed
- group directory names like `(Group)` are excluded from final pathname

# Build Output and Assets

Build flow highlights:

- markdown files are parsed into route/content JSON
- generated data is written under web generated assets
- static app is built and copied to target docs directory

Generated files consumed by the web app:

- `.generated/output.json`: metadata and parsed route content
- `.generated/paths.json`: nested tree used to render sidebar groups/collapsibles

If `publicPath` is configured and exists, that directory is copied as public assets before build.

If no `smm.config.json` or `.smmignore` exists, defaults are used automatically.

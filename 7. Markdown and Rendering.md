# Markdown and Rendering

The CLI uses `markdown-it` and includes:

- footnotes support
- task lists support

Code highlighting is enabled through Prism with language classes like `language-js`.

Useful notes:

- `linkify` is enabled by default in config options.
- `fuzzyEmail` linkification is disabled.
- You can override markdown-it behavior via `markdownItOptions` in `smm.config.json`.

Additional rendering behavior from the web app:

- Heading elements are assigned generated ids for anchor navigation.
- Other extracted elements can receive internal labels for in-page search scroll targets.

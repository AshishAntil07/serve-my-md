# Config Examples

## Basic customization

```json
{
  "rootTitle": "Company Docs",
  "description": "Internal knowledge base",
  "defaultTheme": "dark",
  "sortRoutes": true
}
```

## Ordered file naming + trimmed paths

```json
{
  "sortRoutes": true,
  "trimIndexFromPath": true
}
```

## Public assets

```json
{
  "publicPath": "public"
}
```

This copies `public` from docs root into build public assets, also ignores it for routes building.

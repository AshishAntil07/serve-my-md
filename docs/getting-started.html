Getting Started

Install

npm i -g serve-my-md

Run

serve-my-md --directory .

The CLI scans markdown files in the target directory and generates a static website there. Every page is a standalone HTML file (SSG) — deploy to any static host or CDN.

What gets read automatically

  • smm.config.json at docs root (if present)
  • .smmignore at docs root (if present)
  • fallback to built-in defaults when these files are missing

Important index.md behavior

  • index.md is the landing page for its directory.
  • index is never included in the pathname.
  • Internally, an index.md entry is treated as "" (empty string) in route tree naming.

Example:

docs/
  index.md
  guides/
    index.md
    install.md

Routes:

  • /
  • /guides
  • /guides/install

# Structure Examples

## Group directory (not in pathname)

```text
docs/
  (Category)/
    tos.md
```

Route: `/tos`

## Normal directory with landing page

```text
docs/
  features/
    index.md
    tea.md
```

Routes:

- `/features`
- `/features/tea`

## Root landing page

```text
docs/
  index.md
  about.md
```

Routes:

- `/`
- `/about`

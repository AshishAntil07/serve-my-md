# CLI Reference

## Main command

- `serve-my-md`: build a static docs website from markdown files.

## Options

- `-d, --directory <path>`: docs root path (default `.`).
- `-i, --interactive`: prompt for docs root.

## Behavior notes discovered from source

- Loads config from `./smm.config.json` relative to target directory.
- Loads ignore rules from `./.smmignore` relative to target directory.
- If `publicPath` is set in config, copies that directory into app public assets before build.
- Uses markdown-it with task lists and footnotes plugins enabled.
- Generates OG/meta/font tags in HTML from config values.

## Runtime/navigation behaviors (from web app usage)

- Markdown links with non-HTTP hrefs are intercepted and navigated client-side.
- Intent-based link preloading is used for faster navigation.
- Keyboard shortcuts include:
  - Search: `Ctrl+Shift+F`
  - Next page: `Alt+Enter`
  - Previous page: `Alt+Shift+Enter`
- Search returns matches in current page and across other pages.

## Test-only option

- `--skip-build` exists only in vitest mode, not in normal CLI usage.
